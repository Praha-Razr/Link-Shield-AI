# LinkShield AI - Bundled Fonts

This directory contains TrueType fonts bundled for cross-platform PDF generation (specifically for Linux environments such as Render, where Windows system fonts like Nirmala UI are not available).

- **NotoSansDevanagari-Regular.ttf**: Google Noto Sans Devanagari (SIL Open Font License 1.1)
- **NotoSansDevanagari-Bold.ttf**: Google Noto Sans Devanagari Bold (SIL Open Font License 1.1)

These fonts ensure Hindi characters and bilingual investigation dossiers render correctly without missing glyphs across both Linux and Windows servers.
