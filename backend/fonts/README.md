# LinkShield AI - Bundled Fonts

This directory contains TrueType fonts bundled for cross-platform PDF generation (specifically for Linux cloud environments like Render, where Windows system fonts are not available).

- **NotoSans-Regular.ttf**: Google Noto Sans Regular (SIL Open Font License 1.1) - Primary Latin / English / numbers / symbols typography.
- **NotoSans-Bold.ttf**: Google Noto Sans Bold (SIL Open Font License 1.1) - Primary Latin bold typography.
- **NotoSansDevanagari-Regular.ttf**: Google Noto Sans Devanagari Regular (SIL Open Font License 1.1) - Hindi / Devanagari script typography.
- **NotoSansDevanagari-Bold.ttf**: Google Noto Sans Devanagari Bold (SIL Open Font License 1.1) - Hindi / Devanagari bold typography.

These bundled fonts guarantee that English text, numbers, punctuation, and Hindi characters in investigation dossiers render identically across both Linux and Windows servers without relying on host operating system fonts.
